# sagangromov.github.io

Matheus Horácio’s bilingual geometry notebook and academic archive. The site is deliberately small: Jekyll generates semantic HTML, while one local stylesheet and one small script provide the visual system and progressive enhancement.

## Run locally

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open <http://localhost:4000>.

## Content

- Portuguese lives at `/`, `/pesquisa/`, `/textos/`, and `/recursos/`.
- English lives under `/en/`.
- Shared publications and document metadata live in `_data/`.
- Page templates live in `_pages/`; shared rendering lives in `_includes/`.
- Author-created PDFs live in `assets/pdf/`.

The site has no analytics, cookies, third-party JavaScript, or runtime network dependencies. The repository’s old theme demos and third-party book files were intentionally removed; Git history still records those deletions.
